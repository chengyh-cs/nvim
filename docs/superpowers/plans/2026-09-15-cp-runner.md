# 竞赛测试浮窗实施计划

**目标：** 在当前 Neovim 配置中，用快捷键打开左右分栏浮窗，为 C++ / Python 程序输入 stdin 并查看 stdout。

**设计：** 使用 Neovim 原生浮窗和异步进程 API，不添加外部插件依赖。相比复用终端，自定义 scratch buffer 更方便保留、编辑输入并复制输出；相比安装完整竞赛平台插件，范围更贴合本地测试需求。

**文件职责：** `lua/cp_runner/runner.lua` 管理编译、运行、取消、超时和临时文件；`lua/cp_runner/init.lua` 管理浮窗、源文件保存、会话输入和快捷键；`init.lua` 注册插件；`tests/cp_runner.lua` 运行无外部测试框架的集成测试。

- [x] 先写真实 Python / C++ 执行与浮窗行为测试，确认缺少模块时失败。
- [x] 实现异步 runner：参数数组启动进程，工作目录为源文件目录，C++23 编译到临时目录，Python 复用当前环境解析；保留 stdout / stderr，限制输出大小，提供超时和取消。
- [x] 实现左右浮窗：左侧可编辑，右侧只读；Ctrl+r 保存源文件并运行，Tab 切栏，Ctrl+c 停止，普通模式 q / Esc 关闭；按源文件保留本次会话的输入。
- [x] 接入 `<leader>ti` 和 `:CPTest`，记录使用方法与配置选项。
- [x] 执行 headless 集成测试，检查编译失败、运行错误、空输入、超时、取消、含空格路径、重复运行及关闭清理，检查 diff。

**验证结果：** 23 项集成测试通过。按用户补充要求严格以 `.cpp` / `.py` 后缀判断语言。独立代码审查发现 Unix 子进程可能持有输出管道，已通过独立进程组终止修复，并补充失败后通过的回归测试。

**验证命令：** `nvim --headless -u NONE -i NONE -l tests/cp_runner.lua`。测试使用临时目录，不加载现有第三方插件。
